Zadanie 6 - zadanie teoretyczne (Maciej Huba, klasa 3F)

1) Rodzaje okienek
  • Okienko alert - wyświetla okienko dialogowe z informacją i przyciskiem OK.
  • Okienko prompt - generuje okno, w którym użytkownik może wpisać wartość, zwracaną następnie do programu.
  • Okienko confirm - służy do tego, aby użytkownik coś potwierdził (stąd nazwa confirm).
2) Konwersja liczb
Wczytanie zmiennej z użyciem prompt wykonywane jest jako ciąg znaków, dlatego konieczna jest konwersja z ciągu znaków na wartości liczbowe, aby wykonywać obliczenia.
  • parseFloat(zmienna) - konwersja zmiennej do typu float (zmiennoprzecinkowego),
  • parseInt(zmienna) - konwersja zmiennej do typu int (liczbowego całkowitego),
  • toString(zmienna) - konwersja zmiennej do typu łańcuchowego.
3) Przy nadawaniu nazw zmiennym należy przestrzegać pewnych zasad (trzy zasady):
  1. Nazwa zmiennej musi się zaczynać od litery, znaku "$" lub "_", może zawierać tylko litery (bez polskich znaków), cyfry oraz "$" i "_".
    Poprawne nazwy: zmienna1, $wynik, _rozmiar, wynik1, Rekord, $_gracz
    Błędne nazwy: 1zmienna, wynik gry, wysokosc&szerokosc, wynik.rekord, &gracz, wysokość, imie+nazwisko
  2. Wielkość liter ma znaczenie. Rekord i rekord to dwie różne zmienne!
  3. Należy nie używać słów kluczowych JavaScript jako nazw zmiennych.
4) Omów typy zmiennych w JavaScript
W JavaScript nie definiuje się typów zmiennych tak jak w C++ - typ jest ustalany w trakcie przypisywania wartości.
  • Number - typ liczbowy (liczby całkowite i zmiennoprzecinkowe),
  • String - typ tekstowy,
  • Boolean - typ logiczny (true / false),
  • Null - pusta zawartość,
  • Undefined - typ niezidentyfikowany (zmienna bez przypisanej wartości),
  • Object - obiekt.
