Zadanie 4 - teoria JavaScript (Maciej Huba, klasa 3F)

1) Kiedy powstał JavaScript (podaj datę).
JavaScript powstał w 1995 roku - w grudniu 1995 został zaimplementowany w przeglądarce Netscape Navigator.

2) Dlaczego jest to język skryptowy?
Bo jest językiem interpretowanym - nie trzeba go kompilować do kodu maszynowego, żeby zobaczyć efekty jego działania. Wystarczy przeglądarka internetowa, która ten język obsługuje.

3) Gdzie jest wykonywany JS (klient lub serwer)?
Po stronie klienta - w przeglądarce internetowej użytkownika (dzięki Node.js można go też uruchamiać na serwerze).

4) Dlaczego JS to bezpieczne narzędzie?
Ze względów bezpieczeństwa JavaScript ma znacznie ograniczone uprawnienia dostępu do zasobów komputera, na którym przeglądana jest strona.

5) Czy jest to język obiektowy, jeśli tak to dlaczego?
Tak, bo wykorzystuje definicje obiektów, metod i zdarzeń, które opisują właściwości obiektów. Struktura obiektów jest określana przez DOM (Document Object Model). Można korzystać z gotowych obiektów i metod, tworzyć własne oraz modyfikować istniejące.

6) Wymień zalety JS:
Zaleta1 - prostota: język jest relatywnie łatwy do opanowania.
Zaleta2 - jest najbardziej rozpowszechnionym językiem skryptowym, w Internecie są miliony przykładów jego użycia.
Zaleta3 - uniwersalność oraz odciążenie serwerów i ograniczenie ilości danych przesyłanych między serwerem a przeglądarką.

7) Framework to:
Rodzaj programu (szkieletu) do tworzenia innych programów w JS, np. Angular (Google), React (Facebook), Vue.

8) Do aplikacji mobilnych można użyć Framework:
React Native - pozwala budować aplikacje mobilne na różne systemy operacyjne (cross-platform apps).

9) Aplikacje responsywne to:
Aplikacje, które dopasowują się do rozmiaru ekranu - JavaScript pobiera bieżący rozmiar ekranu, a przy pomocy CSS i HTML zmienia się rozmiar, ukrywa, zmniejsza, powiększa lub przenosi treści, aby wyglądały dobrze na dowolnym urządzeniu.

10) Przepisz linię kodu, pod nią wytłumaczenie jak działa ten fragment kodu
‹input type="button" name="przycisk" value="Nowa Strona" onclick="WinOpen(' ')"›
Tworzy przycisk (pole formularza typu button) o nazwie "przycisk" z napisem "Nowa Strona". Po kliknięciu przycisku (zdarzenie onclick) wywoływana jest funkcja JavaScript WinOpen(), która otwiera nowe okno.

11) Przepisz linię kodu, pod nią wytłumaczenie jak działa ten fragment kodu
window.open("obraz.html","okienko","toolbar=no,directories=no,menubar=no,height=280,width=160,top=200,left=200");
Metoda open obiektu window otwiera nowe okno przeglądarki i wczytuje do niego plik obraz.html. "okienko" to nazwa nowego okna, a trzeci parametr to lista opcji wyglądu okna:
toolbar=noukrywa pasek narzędzi (przyciski Wstecz, Dalej, Odśwież)
directories=noukrywa pasek katalogów / zakładek (przyciski katalogów)
menubar=noukrywa pasek menu (Plik, Edycja, Widok...)
height=280wysokość okna - 280 pikseli
width=160szerokość okna - 160 pikseli
top=200odległość okna od górnej krawędzi ekranu - 200 pikseli
left=200odległość okna od lewej krawędzi ekranu - 200 pikseli

12) Opisz następującą instrukcję window.close()
Metoda close() obiektu window zamyka bieżące okno przeglądarki (to, w którym wykonano skrypt). Najczęściej używa się jej w funkcji podpiętej pod przycisk "zamknij okno".
