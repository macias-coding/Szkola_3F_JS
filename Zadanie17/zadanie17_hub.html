2. Czym jest funkcja w JS?
- to zbiór instrukcji, który uruchamiamy podając jego nazwę,
- po wywołaniu wykonuje swój wewnętrzny kod,
- może mieć argumenty, np. suma_hub(a, b),
- może zwrócić wartość po słowie return.

3. Omów metody getElementsByName, getElementById, getElementsByTagName
MetodaOpis
getElementById("id")dostęp do elementu o danej wartości atrybutu id
getElementsByTagName("znacznik")dostęp do elementów o danym znaczniku, np. P lub DIV
getElementsByName("nazwa")dostęp do elementów o danej wartości atrybutu name

4. Omów właściwości innerHTML, innerText, className
innerHTML - pozwala odczytać, zmienić, wstawić lub usunąć kod HTML w elemencie.
innerText - określa tekst, który zostanie umieszczony w elemencie.
className - określa klasę CSS elementu.
